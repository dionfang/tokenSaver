TokenSaver 直接部署

Direct deploy. Requires Node.js >= 18 and git. Ollama, if used, must already be installed, started, and have its models pulled by you; this tool does not start the service or pull models. The local path needs no Ollama. Model names are set in config.mjs in this directory. Ollama weights are not copied with this directory. The two transformers.js models live in hf-cache (about 439MB) and should be copied along. Preferred: run init inside TokenSaver\code-index. Index data is written to TokenSaver\data, not into the repositories you index. You can also copy this directory into a target project (suggested scripts\code-index); data then sits in a sibling data\ directory. If this directory is itself the git root, data is written to data\ inside it. Override the location with CODE_INDEX_DATA_DIR. An npm install always uses the repo's scripts\data. init installs dependencies, writes config, attaches hooks for the current agent (Cursor, ZCode, and Qoder when it cannot tell which), and builds and warms the index in the background. Check readiness with node status.mjs.

前提: Node.js >= 18、git。
用 ollama 时,本机需已安装并自行启动 Ollama,并先手工 pull 模型。本工具不拉起服务,也不自动 pull。
用 local 时不需要 Ollama。模型名改本目录 config.mjs。
Ollama 模型不随本目录复制。transformers.js 两个 local 模型在本目录 hf-cache(约 439MB),请一起复制。

作为独立工具(推荐):在 TokenSaver\code-index 执行 init。数据写在 TokenSaver\data,不写进业务仓。
  node init.mjs --roots "D:/业务仓A,D:/业务仓B"
以后改 data\code-index.config.json 的 roots,再跑一次不带参数的:
  node init.mjs
即可把新目录编进索引并给那些 git 仓挂钩子。

也可把本目录复制到目标项目(建议 scripts\code-index),数据则在与本目录平级的 data\。若本目录本身就是 git 根,则写在本目录 data\。可用环境变量 CODE_INDEX_DATA_DIR 改位置。npm 安装固定用仓库 scripts\data。

init 会安装依赖、写配置、接线当前 agent 的 hook(认不出则 Cursor/ZCode/Qoder 都接),并后台建索引+预热。确认就绪: node status.mjs

从 GitCode 拉源码后同样只跑 init:
  git clone https://gitcode.com/dionfang/TokenSaver.git
  cd TokenSaver/code-index
  node init.mjs

复制细节

1. 复制的是本目录。可放在项目任意位置,建议 scripts\code-index。
   必须带上 hf-cache(两个 local 模型)。不要带 node_modules,不要带 data\。
2. 在该目录执行:
   node init.mjs [--roots "<路径1>[,<路径2>...]"] [--model-in ollama|local] [--hooks all|cursor|zcode|qoder]
3. 确认是否就绪: node status.mjs

init 会写配置并安装依赖。
参数名写错、缺少取值,或 --model-in / --hooks 取值非法时,报错退出且不改配置。
--roots=路径 与 --model-in=local 这种写法也可以。

--roots
  逗号分隔的扫描目录,写入本工具仓 data\code-index.config.json。路径用 D:/proj 或 D:\proj。
  不传且还没有配置:用工具仓 git 根。
  不传且已有配置:按文件里的 roots 自愈(仍存在的保留,失踪的按兄弟目录猜一次);要让工具自身代码入索引,把工具仓写进 roots(或 --roots)即可;然后给这些 git 仓挂钩子并后台建索引。
  传入:与已有 roots 合并(纳入,不去掉旧的)。不存在的路径跳过。要删目录请改 JSON 后重跑不带参的 init。

--hooks
  all | cursor | zcode | qoder。只写选中工具的会话 hook,不改其他工具已有文件。
  不传:能从环境变量认出当前 agent 就只装那一套(Cursor: CURSOR_AGENT;Qoder/ZCode: 各自 PROJECT_DIR)。
  认不出(例如系统终端里跑):三套都装。

--model-in
  ollama 或 local。写入 modelIn,不改模型名。
  新建配置时不传则为 local。已有配置时不传则保持原路径。
  ollama 需先执行:
    ollama pull qwen3-embedding:0.6b
    ollama pull sam860/qwen3-reranker:0.6b-F16
  模型名若在 config.mjs 里改过,pull 改为改后的名字。
  local 的两个模型已放在本目录 hf-cache;缺失时才下载。

配置

模型部署只改本目录 config.mjs。data JSON 里的同名项无效。
  models.embedding        默认 qwen3-embedding:0.6b
  models.reranker         默认 sam860/qwen3-reranker:0.6b-F16
  models.localEmbedding   默认 Xenova/jina-embeddings-v2-base-zh
  models.localReranker    默认 Xenova/bge-reranker-base
  ollamaBase              默认 http://localhost:11434
  gpu                     auto | cpu | gpu,默认 auto
  OLLAMA_KEEP_ALIVE       默认 2h
  OLLAMA_NUM_CTX          默认 4096

项目配置在与本目录平级的 data\code-index.config.json(建议路径下即 scripts\data;可用环境变量 CODE_INDEX_DATA_DIR 改位置)。未写的键用 config.mjs 的默认值。
  roots              扫描目录。--roots > 环境变量 CODE_INDEX_ROOTS > 本文件
  modelIn            ollama | local。--model-in > 本文件 > local
  skipDirs           跳过的目录名。写了就整表替换,不是追加
  exts               收录的扩展名,不带点
  jsonWhitelist      允许收录的 json 文件名。默认 package.json、pages.json、manifest.json、tsconfig.json
  maxFileBytes       单文件上限。默认 819200
  readMaxLines       全量读行数上限,默认 500。超过 ×1.25 由 Cursor preToolUse / ZCode·Qoder PreToolUse 拦截,对象是全量 Read 与 Bash 里各链式组末段的 cat 整读(带 | 限量管道、> 重定向放行);Read 带 offset/limit 的区间读不受限。拒绝信息自带替代方案(检索 / 区间读 / grep -n)。同一目标 5 分钟内重试一次即放行。设很大等于关掉。
  chunk              targetLines 70,maxLines 120,overlapLines 10,minTail 15
  staleNonGitMs      非 git 目录多久重建一次,毫秒。默认 86400000
  knownAnnotations   "项目名/相对路径" → 一句职责

skipDirs 默认已跳过依赖、构建产物和编辑器目录。新生成的配置还会加上 code-index、.cursor、.zcode。

English

TokenSaver direct deploy

Requirements: Node.js >= 18 and git.
For Ollama, install it, start it yourself, and pull the models by hand. This tool does not start the server and does not pull models.
local does not need Ollama. Change model names in config.mjs in this directory.
Ollama models are not copied with this directory. The two transformers.js local models live in hf-cache (about 439MB); copy that directory too.

Standalone tool (recommended): run init in TokenSaver\code-index. Data is written to TokenSaver\data, not into application repos.
  node init.mjs --roots "D:/app-a,D:/app-b"
Later, edit roots in data\code-index.config.json and run init again with no arguments:
  node init.mjs
That indexes the new directories and installs hooks in those git repos.

You can also copy this directory into the target project (suggested: scripts\code-index). Data then lives in data\ next to this directory. If this directory is itself the git root, data is written to data\ inside it. Override the location with CODE_INDEX_DATA_DIR. An npm install always uses the repo's scripts\data.

init installs dependencies, writes config, wires the current agent's hooks (if it cannot tell which agent, it wires Cursor, ZCode, and Qoder), then builds the index and warms models in the background. Check readiness: node status.mjs

After cloning from GitCode, init is still the only step:
  git clone https://gitcode.com/dionfang/TokenSaver.git
  cd TokenSaver/code-index
  node init.mjs

Copying

1. Copy this directory. It can sit anywhere in the project; scripts\code-index is the suggested path.
   hf-cache (the two local models) must come along. Do not copy node_modules or data\.
2. In that directory run:
   node init.mjs [--roots "<path1>[,<path2>...]"] [--model-in ollama|local] [--hooks all|cursor|zcode|qoder]
3. Check readiness: node status.mjs

init writes config and installs dependencies.
A bad flag name, a missing value, or an illegal value for --model-in or --hooks exits with an error and does not change config.
--roots=path and --model-in=local are also accepted.

--roots
  Comma-separated scan directories, written to data\code-index.config.json in this tool repo. Use D:/proj or D:\proj.
  Omitted, and no config yet: the tool repo's git root.
  Omitted, and config already exists: heal roots from the file (keep paths that still exist; guess a missing one once from a sibling directory). To index the tool's own code, list the tool repo in roots (or pass --roots). Then install hooks in those git repos and build the index in the background.
  Passed: merge into the existing roots (add, do not drop old ones). Skip paths that do not exist. To remove a directory, edit the JSON and run init again with no arguments.

--hooks
  all | cursor | zcode | qoder. Writes session hooks only for the selected tool and does not change files already written for the others.
  Omitted: if the environment identifies the current agent, install only that set (Cursor: CURSOR_AGENT; Qoder/ZCode: their own PROJECT_DIR).
  If it cannot tell (for example a system terminal): install all three.

--model-in
  ollama or local. Writes modelIn and does not change model names.
  Omitted on a new config: local. Omitted when config already exists: keep the current path.
  ollama requires, first:
    ollama pull qwen3-embedding:0.6b
    ollama pull sam860/qwen3-reranker:0.6b-F16
  If the names were changed in config.mjs, pull the new names.
  The two local models are already in hf-cache in this directory; they are downloaded only when missing.

Configuration

Model deployment is edited only in config.mjs in this directory. The same keys in the data JSON are ignored.
  models.embedding        default qwen3-embedding:0.6b
  models.reranker         default sam860/qwen3-reranker:0.6b-F16
  models.localEmbedding   default Xenova/jina-embeddings-v2-base-zh
  models.localReranker    default Xenova/bge-reranker-base
  ollamaBase              default http://localhost:11434
  gpu                     auto | cpu | gpu, default auto
  OLLAMA_KEEP_ALIVE       default 2h
  OLLAMA_NUM_CTX          default 4096

Project config is data\code-index.config.json next to this directory (under the suggested path that is scripts\data; override with CODE_INDEX_DATA_DIR). Missing keys use the defaults in config.mjs.
  roots              Scan directories. --roots > env CODE_INDEX_ROOTS > this file
  modelIn            ollama | local. --model-in > this file > local
  skipDirs           Directory names to skip. When set, the list replaces the default; it is not appended
  exts               Extensions to index, without the dot
  jsonWhitelist      JSON file names allowed in the index. Default: package.json, pages.json, manifest.json, tsconfig.json
  maxFileBytes       Per-file size cap. Default 819200
  readMaxLines       Full-read line cap, default 500. Above ×1.25, Cursor preToolUse / ZCode and Qoder PreToolUse block both a full Read and a trailing-pipeline cat in Bash (piped limiters like head/grep and > redirects pass). A ranged read with offset/limit is not capped. Denials carry alternatives (index search / ranged read / grep -n). One retry of the same target within 5 minutes is allowed. A very large value turns the cap off.
  chunk              targetLines 70, maxLines 120, overlapLines 10, minTail 15
  staleNonGitMs      How often a non-git directory is rebuilt, in milliseconds. Default 86400000
  knownAnnotations   "project/relative-path" → one line on what the file does

skipDirs already skips dependencies, build output, and editor directories. Newly generated config also adds code-index, .cursor, and .zcode.

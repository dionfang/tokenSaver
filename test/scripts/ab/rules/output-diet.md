## 输出纪律(省话不省工)

本段只约束「说话与轮次」。禁止以此削减实现完整性:该写的功能、边界处理、错误处理一行不少,验收不过必须修到过。

1. 思考只花在有出错风险的决策上:边界条件、解析规则、状态与并发、易错细节。机械步骤——读题、定路径、套已知写法、唯一合理的选择——不在思考里复述、预演或罗列方案,直接调用工具。
2. 相邻工具调用之间零过渡文字(不写「现在/接下来/让我」)。过程叙述全省;最终回复只说结果,外加用户必须知道的一两句。
3. 一次调用能做完的不拆成多次:新文件一次 Write 写出完整内容,不先写半份再 Edit 补;同类小操作合并;一条命令能完成的不拆三条。
4. 不在回复或思考里粘贴、转写刚写过的代码,不复述题目原文;文件就是交付物。
5. 验证一次到位:写完跑一遍覆盖核心路径的检查,通过即结束;不逐块反复跑,不重复已通过的检查。

## 输出纪律·最少轮次(省话不省工)

只约束说话、思考冗余与轮次;禁止以此砍实现——功能、边界、错误处理必须完整,检查不过必须修到过。

1. 常规小任务按两步走:第一步「简短思考 + 新文件一次 Write 写全 + 发出一条验证命令」,第二步看结果后一句话收尾。不先写半份再 Edit 补,不试探性多轮。
2. 思考只留给易错处:边界条件、解析规则、状态推演。不复述题目、不预演已知写法、不罗列被否决的备选方案。
3. 工具调用之间零过渡文字;最终回复一句话,只报结果。
4. 修改已有文件用最小 Edit,只动要改的行,不整文件重写。
5. 交付前必须跑一次能判定对错的检查(一条命令或一个断言);不搭测试脚手架,不重复跑已通过的检查。
